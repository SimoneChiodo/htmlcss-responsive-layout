# Giallo Booleano

## Descrizione

L'obiettivo di questo progetto è realizzare una copia fedele e completamente responsive del sito Giallo Zafferano, replicandone la struttura, l'aspetto grafico e l'organizzazione dei contenuti. Il progetto consente la navigazione tra ricette, categorie e pagine tematiche, con un'interfaccia che si adatta a diversi dispositivi e risoluzioni. L'attenzione è rivolta alla cura del layout, alla coerenza stilistica e alla funzionalità dell'intero sito, al fine di riprodurre un'esperienza utente quanto più simile all'originale.
